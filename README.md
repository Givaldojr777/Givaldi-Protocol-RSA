This repository hosts the experimental data validating the "Givaldi Protocol," a deterministic approach to integer factorization based on Base-60 Sexagesimal Geometry. Unlike classical brute-force methods (GNFS), which scale exponentially, this protocol demonstrates that semiprimes ($N = P \times Q$) possess a fixed geometric address.

Instead, we present the **"8x4 Vector Mask"**:

* This hash maps to a specific cell in an **8x4 Look-Up Table**.
* The table returns a "Vector of Correction" (e.g., 11, 29, 106).
* **Result:** $(N + \text{Vector}) / 3$ reveals the geometric neighborhood of the factors.
